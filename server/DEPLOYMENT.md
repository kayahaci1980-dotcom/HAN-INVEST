# HAN INVEST Paper Trading — серверная настройка

## Что делает сервер

- Только виртуальная Spot-торговля; реальные ордера на Binance и Bybit не отправляются.
- Начальный виртуальный баланс: 1 000 USDT.
- Комиссия симуляции: 0,1% при покупке и 0,1% при продаже.
- Риск для расчёта размера позиции: 1% от начального капитала.
- Не более трёх открытых виртуальных позиций одновременно.
- Проверка Binance и Bybit выполняется фоновым worker-процессом каждые 300 секунд, пока серверный процесс работает.
- BUY разрешён только при подтверждённом сигнале сканера, валидной Spot-паре и состоянии BTC BULLISH.
- Позиции закрываются по Stop Loss или Take Profit при получении свежей цены. Если актив отсутствует в ответе или данные недоступны, сервер не закрывает позицию по устаревшей цене.

## Обязательная настройка Render

Для сохранения баланса и истории после перезапуска нужен постоянный диск. Сам код не может включить его в панели хостинга.

1. Откройте Web Service HAN INVEST в Render.
2. Убедитесь, что сервис развёртывает ветку `crypto-v0.6.0` и использует каталог `server` как Root Directory (или соответствующую Docker-конфигурацию).
3. Добавьте Persistent Disk с mount path `/var/data`.
4. В Environment добавьте:
   - `PAPER_DB_PATH=/var/data/han-invest-paper.sqlite3`
   - `PAPER_SCAN_INTERVAL_SECONDS=300`
5. Используйте постоянно работающий экземпляр сервиса. Спящий/free-инстанс не обеспечивает непрерывную торговлю.
6. После деплоя проверьте `/health` и `/api/v1/paper/state`. В ответе state поле `storage_persistent_configured` должно быть `true`.

Если `PAPER_DB_PATH` не задан, база создаётся в `/tmp`; она подходит только для проверки и может исчезнуть после перезапуска/переразмещения контейнера. Не включайте автоматический режим до настройки постоянного диска и проверки API.

## API

- `GET /api/v1/paper/state` — баланс, открытые позиции, история и состояние worker.
- `POST /api/v1/paper/enable` — включить виртуальную автоматическую торговлю.
- `POST /api/v1/paper/disable` — остановить новые сделки и автоматическое закрытие; открытые позиции останутся открытыми.

Worker запускается вместе с FastAPI. Когда режим выключен, сканирование для автоторговли не выполняется. Включение режима инициирует немедленный цикл сканирования.

## Важные ограничения

- Работа 24/7 зависит от доступности и тарифа хостинга, а не только от Android-приложения.
- Публичные рыночные API могут ограничивать запросы или временно быть недоступны.
- Симуляция не моделирует проскальзывание, частичное исполнение, точность лотов и реальные комиссии аккаунта.
- Это тестовый симулятор, не гарантия доходности и не финансовая рекомендация.

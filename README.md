# HAN-INVEST
HAN INVEST — инвестиционный аналитический Android-помощник

## Интерфейс биржевого сканера
В рабочей ветке `ui-exchange-tabs-top3` криптосканер показывает отдельные вкладки Binance Spot и Bybit Spot. По умолчанию отображаются три лучших кандидата выбранной биржи; полный список раскрывается отдельно. Данные двух бирж не смешиваются.
